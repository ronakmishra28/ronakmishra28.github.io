Home Lab - WAF - Web Security
SafeLine WAF - Web Attack Detection and Blocking Lab
Read Full Report GitHub

Deployed DVWA on Ubuntu and used Kali Linux to execute live SQL Injection, XSS, and HTTP Flood attacks - confirmed exploitable without protection. Then placed SafeLine WAF (Docker-based reverse proxy) in front of the application, configured rate limiting, IP blocking, and injection detection rules, and re-ran every attack.

All attacks blocked. Real-time dashboard logs showed source IP, matched rule, payload, and timestamp for each blocked request - the same alert triage workflow SOC analysts use when investigating suspicious web traffic.

pfSense Firewall Home Lab - SYN Flood Attack Simulation and Blocking
Read Full Report GitHub

Built a dual-network lab with pfSense 2.8.1 as the perimeter firewall - Kali Linux on WAN as the attacker, Ubuntu on LAN as the protected host. Launched a SYN flood via hping3 at ~30,000 packets/sec and confirmed impact with Wireshark before any rules were in place.

Created custom WAN firewall rules to block the attacker IP and SYN flood traffic - re-ran the attack and verified full blocking via pfSense firewall logs. Covers perimeter defense, DoS mitigation, and the log review cycle that mirrors real SOC triage.
